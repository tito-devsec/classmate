## Contributing

1. Branch from `main`.
2. Keep the web app working without a backend — every API call needs a fallback or a graceful
   empty state.
3. Run `npm run lint`, `npm test` and `npm run api:smoke` before opening a pull request.
4. Commit as `tito-devsec`:

```bash
git config user.name "tito-devsec"
git config user.email "tito-devsec@users.noreply.github.com"
```
